WinTuneUp
Free Windows 10/11 optimizer and maintenance toolkit — cleanup, startup, privacy, disk health, uninstall leftovers, app updates, all in one app with undo.
Optimizator și instrument de întreținere pentru Windows 10/11 — gratuit, cu anulare pentru schimbări.

Click Next → Next → Install. WinTuneUp appears in your Start menu.
Integrity: every release includes a `.sha256` file; the app also verifies its own updates with SHA-256.
What it does
Area	Features
One-click maintenance	Cleanup, health check with a green/yellow/red traffic light, optional restore point. Can run automatically on a schedule and write an HTML report.
Disk cleanup	Temp files, Windows Update cache, crash dumps, error reports, thumbnails, shader caches, old Prefetch, font cache, Chrome / Edge / Firefox / Brave / Vivaldi / Opera / Chromium caches, Recycle Bin, recent documents, clipboard, your own custom folders. Risky or privacy-related items are unticked by default.
Disk health (SMART)	Status, remaining life of SSD/NVMe, temperature, power-on hours and the full SMART attribute table for every HDD / SSD / NVMe — read-only.
Disk usage & duplicates	See what takes the space; find identical files (SHA-256) and move the copies to the Recycle Bin.
Programs	Uninstall with a leftover search (folders and shortcuts, Recycle Bin as undo), app updates through winget, and program lists to reinstall your apps in bulk after a Windows reinstall.
Startup & boot	Startup entries, scheduled tasks, services, and what slowed your last boots (from Windows' own log).
Privacy & tweaks	Telemetry and privacy tweaks, ready-made profiles (gaming, laptop, privacy, office), removal of preinstalled apps, DNS provider switcher.
Safety	Restore point offer, History & undo for tweaks, Recycle Bin for deletions, protected paths that are never touched.
For admins	Command line (`--maintenance`, `--health`, `--export-programs`, `--install-programs`, …), settings backup/restore.
Accessibility	Dark / light / system / high-contrast themes, large text, keyboard shortcuts.
Languages: Română · English · Deutsch · Español · Français.
Privacy
No ads, no account, no telemetry. The only network use is the optional update check on GitHub (can be turned off in Settings) and winget when you ask for app updates or program lists.
