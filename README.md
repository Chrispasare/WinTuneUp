# WinTuneUp

Utilitar de optimizare și întreținere pentru Windows 10/11 (curățare disc, pornire și servicii, confidențialitate, informații sistem).
Optimization and maintenance utility for Windows 10/11.

**Program realizat de Pasare Cristian · Created by Pasare Cristian**

## Descărcare / Download

Ultima versiune: [Releases](../../releases/latest) → `WinTuneUp-Setup-x.y.z.exe`.
Verificarea integrității: fișierul `.sha256` de lângă installer. Aplicația se poate actualiza singură din **Setări → Actualizări**.
